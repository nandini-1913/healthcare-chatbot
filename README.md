# 🏥 Talking Healthcare Chatbot using Deep Learning

## 📌 Project Overview
This project is a Healthcare Chatbot built using Deep Learning and NLP techniques.  
It can understand user symptoms and provide basic medical guidance based on trained intents.

---

## 🚀 Features
- NLP-based intent classification
- Deep Learning model using TensorFlow/Keras
- Interactive chatbot system (CLI-based)
- Healthcare-focused responses

---

## 🧠 Technologies Used
- Python
- TensorFlow / Keras
- NLTK
- NumPy

---

## 📂 Dataset
- Custom `intents.json`
- Based on medical Q&A (MedQuAD dataset)

## ⚙️ How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt

2. Train the model
python train.py

3. Run the chatbot
python chatbot.py

💡 Example
User: fever  
Bot: You might have flu. Stay hydrated and consult a doctor.
