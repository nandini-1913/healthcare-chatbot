# 🏥 Talking Healthcare Chatbot using Deep Learning

## 📌 Project Overview
This project is a Healthcare Chatbot built using Deep Learning and NLP techniques. It can understand user symptoms and provide basic medical guidance.

## 🚀 Features
- NLP-based intent classification
- Deep Learning model (TensorFlow/Keras)
- Interactive chatbot system
- Healthcare-focused responses

## 🧠 Technologies Used
- Python
- TensorFlow / Keras
- NLTK
- NumPy

## 📂 Dataset
- Custom intents.json (based on medical Q&A / MedQuAD dataset)
